# 제품 영상형 품질 개선: 음성 안내문·장면 대본·크롭·음성 선택

## 변경 범위

- **TTS 안내문 발화**: 기존 `generate_voiceover`는 `"다음 한국어 대본을 자연스럽게 읽으세요..." + text`를 모델에 직접 넘겼다. 이제 `contents=text`로 **실제 내레이션만** 보낸다. 모델이 임의 내용을 추가하지 않는지는 실계정 청취 검증 필요.
- **장면별 대본**: 제품 대본 프롬프트에 각 장면의 실제 업로드 노트에 대응하는 `segments[].narration`을 요구한다. UI에 소스별 편집란과 전체 대본 미리보기를 제공한다. 수정할 때 `full_narration`을 순서대로 재생성한다. 서버의 생성 사전 검사는 빠진/빈 장면 대본을 거절한다.
- **장면 시간 배분**: 기존 사용자 지정 사진 노출시간/선택 비디오 길이에 비례하던 장면 시간 대신 장면별 발화 글자 수에 비례해 음성 총 길이를 배분. **정확한 음소/단어/문장 싱크를 보장하지 않음**. 후속 개선: 음성 타임스탬프 기반 정렬 또는 구간별 합성(호출 수/비용 상승) 필요.
- **원본 잘림**: scene.fit = contain(default) / cover. contain은 영상·사진 비율 유지 후 검정 여백 추가, cover는 9:16 화면을 채우는 대신 가장자리를 자른다. 기존 `crop` 위치는 cover에서 사용.
- **목소리**: Gemini prebuilt 목소리 30개를 검증 허용 목록과 UI에 추가했다. 각 음성이 실제 한국어로 얼마나 자연스러운지는 미검증. 음성 선택만으로 TTS 요금이 달라지는지는 계정에서 확인.
- 기존 권리 확인, 유료 Gemini 명시 동의, 동일 request ID 중복 요청 방지 및 사용자 파일 권한 확인 유지.

## 아직 필요한 검증

1. `pytest -q tests/test_product_video.py tests/test_gemini_tts.py`
2. `cd dashboard && npm run build` 및 제품형 Playwright 회귀
3. 사용자 키/계정으로 확인된 Gemini TTS 모델에 대본만 전달했을 때 실제 녹음이 지시문 없이 시작하는지 청취
4. 다양한 비율 사진/가로 영상에서 contain/cover 실제 렌더 확인
5. 한국어 장면별 문장 시작/종료점이 화면 전환과 어느 정도 일치하는지 검수

**이 브랜치는 미실행 코드 변경이며, 실제 합성 테스트 통과를 주장하지 않는다.** 이전 쿠팡 가져오기 브랜치와 별개이고 main에는 병합하지 않는다.
