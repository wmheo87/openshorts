# 쿠팡 상품 페이지 → OpenShorts (MVP)

## 설치 및 사용
1. GitHub 브랜치 `feature/coupang-product-import-mvp`를 체크아웃한다.
2. Chrome `chrome://extensions` → **개발자 모드** → **압축해제된 확장 프로그램 로드** → `tools/coupang-extension` 폴더 선택.
3. 브라우저에서 쿠팡 상품 상세페이지를 열고 필요한 **상품평 탭**을 표시한다. 상세 이미지가 지연 로딩될 수 있으므로 상품 상세 영역도 내려본다.
4. 확장 프로그램 아이콘 → 확인 체크 → **현재 페이지 분석 및 JSON 저장**. 결과 파일은 브라우저 로컬에만 다운로드된다.
5. OpenShorts **제품 영상형 제작** → **쿠팡 상품 분석 JSON 불러오기**에서 다운로드한 JSON 선택.
6. 참고용으로 추가된 상품 설명·리뷰 발췌를 확인/수정한다. **권리 확보된 이미지/영상 파일만** 기존 업로드에서 직접 선택해 제품 쇼츠를 만든다.

## 실제 수집 범위

- 상품 갤러리: `.product-image img` 에서 현재 DOM 이미지 URL·해상도·고화질 *후보* 생성
- 상품 상세: `.product-detail-content-inside img` (lazy loading은 URL만 보존될 수 있음)
- 리뷰: `article` 안의 `div.twc-break-all` (현재 렌더된 화면에서 최대 50건, 작성자/프로필/리뷰 사진 미수집)
- 상품명: 현재 화면의 `h1`
- 추천상품, 페이지 전체 이미지, 쿠키, 토큰, 인증정보는 읽거나 전송하지 않음
- JSON에 고화질 후보 주소를 넣지만 URL 변환 결과가 실제 존재하거나 사용 가능한지 검증한 것은 아님

## 의도적으로 하지 않는 것

- 쿠팡 403, CAPTCHA 또는 접근 제어 우회
- 내부 XHR 리뷰 API의 대량 수집·반복 요청
- CDN 이미지의 무단 다운로드·상품 이미지 자동 업로드
- 리뷰 5,130건 전체를 분석한 것처럼 표시
- 리뷰 원문을 영상에 무단 재게시
- URL 하나로 무인 자동 제작: **이 MVP는 사용자의 브라우저 클릭과 합법적인 원본 업로드가 필요**

## 확인 필요

쿠팡 UI 선택자는 변경될 수 있다. 현재는 사용자가 제공한 실측 구조 기준이며 실제 브라우저 회귀 검증, Chrome 확장 배포·심사, 상업 이용 권한, 실제 Gemini API 및 로컬 FFmpeg 결과 검증은 별개 작업이다.

보안: 확장은 `activeTab` 및 `scripting`만 요청하고, 사용자 클릭 시 쿠팡 상품페이지의 DOM만 읽는다. 다른 서비스로 HTTP 요청하거나 브라우저 쿠키를 가져가지 않는다.
